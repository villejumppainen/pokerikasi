// Pokerikäsi

Jaa itsellesi kaksi korttia ja viisi pöytäkorttia, ja sovellus kertoo, minkä käden sait. Mukana myös käsien arvojärjestys ja historia aikaisemmin jaetuista käsistä.

Tehty Reactilla ja Vitellä. Kortit tulevat Deck of Cards API:sta (https://deckofcardsapi.com/), ulkoasu React-Bootstrapista, navigointi React Routerista ja käden tunnistus pokersolver-kirjastosta.
